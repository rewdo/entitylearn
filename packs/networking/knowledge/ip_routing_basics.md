# IP路由基础

## IP地址

IP地址（Internet Protocol Address）是分配给网络中每台设备的逻辑地址，相当于"网络世界的门牌号"。

### IPv4地址格式

- **长度**：32位（4字节）
- **表示法**：点分十进制，每8位一组，如 `192.168.1.1`
- **范围**：0.0.0.0 ~ 255.255.255.255
- **总容量**：约43亿个地址（2^32）

### IP地址分类

| 类别 | 范围 | 默认掩码 | 用途 |
|------|------|----------|------|
| A类 | 1.0.0.0 ~ 126.255.255.255 | 255.0.0.0 (/8) | 大型网络 |
| B类 | 128.0.0.0 ~ 191.255.255.255 | 255.255.0.0 (/16) | 中型网络 |
| C类 | 192.0.0.0 ~ 223.255.255.255 | 255.255.255.0 (/24) | 小型网络 |
| D类 | 224.0.0.0 ~ 239.255.255.255 | - | 组播 |
| E类 | 240.0.0.0 ~ 255.255.255.255 | - | 保留/实验 |

### 私有IP地址（RFC 1918）

这些地址不会在公网路由，用于内部网络：

| 类别 | 私有地址范围 |
|------|-------------|
| A类 | 10.0.0.0 ~ 10.255.255.255 |
| B类 | 172.16.0.0 ~ 172.31.255.255 |
| C类 | 192.168.0.0 ~ 192.168.255.255 |

你家里路由器的 192.168.1.x 就是C类私有地址。

### 特殊IP地址

| 地址 | 含义 |
|------|------|
| 0.0.0.0 | 表示所有IP地址，常用于默认路由 |
| 127.0.0.1 | 环回地址（localhost），指向本机 |
| 255.255.255.255 | 受限广播地址 |
| 169.254.x.x | 自动私有地址（APIPA），DHCP失败时自动分配 |

## 子网掩码

子网掩码（Subnet Mask）的作用是**区分IP地址中的网络部分和主机部分**。

```
IP地址：  192 . 168 .  1  .  10
        11000000.10101000.00000001.00001010

子网掩码：255 . 255 . 255 .  0
        11111111.11111111.11111111.00000000

网络部分：192.168.1.0    （前24位 = 子网掩码中为1的位）
主机部分：           .10  （后8位  = 子网掩码中为0的位）
```

### CIDR表示法

`192.168.1.0/24` 中 `/24` 表示子网掩码有24个连续的1，即 `255.255.255.0`。

常用CIDR：

| CIDR | 子网掩码 | 可用主机数 |
|------|---------|-----------|
| /8 | 255.0.0.0 | 16,777,214 |
| /16 | 255.255.0.0 | 65,534 |
| /24 | 255.255.255.0 | 254 |
| /30 | 255.255.255.252 | 2 |

### 判断是否在同一子网

两台主机通信前，会用各自的子网掩码与目标IP做"按位与"运算：
- 结果相同 → 同一子网 → 直接通信（通过交换机，不需要路由器）
- 结果不同 → 不同子网 → 必须通过路由器（默认网关）转发

```
主机A：192.168.1.10/24  想知道 192.168.1.20 是否同子网？
  192.168.1.20 & 255.255.255.0 = 192.168.1.0 ✓ 同子网

主机A：192.168.1.10/24  想知道 10.0.0.5 是否同子网？
  10.0.0.5 & 255.255.255.0 = 10.0.0.0 ✗ 不同子网 → 发给默认网关
```

## 路由表

路由表是路由器的核心数据结构，决定每个数据包的转发方向。

### 路由表项结构

| 字段 | 含义 | 示例 |
|------|------|------|
| 目标网络 | 数据包的目标网络地址 | 192.168.2.0/24 |
| 下一跳 | 转发到的下一个路由器地址 | 10.0.0.1 |
| 出口接口 | 从哪个接口发出 | eth0 |
| 度量值（Metric） | 路径"代价"，越小越优先 | 1 |
| 来源 | 路由的学习方式 | static/ospf/direct |

### 路由表项类型

1. **直连路由**：路由器接口直接连接的网络，优先级最高
2. **静态路由**：管理员手动配置的路由
3. **动态路由**：通过路由协议（OSPF、BGP等）自动学习的路由
4. **默认路由**：`0.0.0.0/0`，匹配所有未命中其他条目的数据包

### 最长前缀匹配原则

路由器查表时，选择**子网掩码最长（即最精确）的匹配条目**。

```
路由表：
  10.0.0.0/8    → 下一跳 A
  10.1.0.0/16   → 下一跳 B
  10.1.2.0/24   → 下一跳 C

数据包目标IP：10.1.2.5
  ✓ 匹配 10.0.0.0/8   (前缀长度 8)
  ✓ 匹配 10.1.0.0/16  (前缀长度 16)
  ✓ 匹配 10.1.2.0/24  (前缀长度 24) ← 最长匹配，选择这条
```

## 默认网关

默认网关（Default Gateway）是当主机不知道目标地址的具体路由时，**把数据包交给谁来处理**。

- 对于终端设备（你的电脑），默认网关通常是你家路由器的LAN口地址（如192.168.1.1）
- 数据包到达默认网关后，由它继续查路由表转发

> 没有默认网关，你就只能访问局域网内的设备，无法上网。

## 下一跳

"下一跳"（Next Hop）是路由表中的关键概念：**数据包下一步要发给哪个路由器**。

数据包从源到目标，可能经过多个路由器。每个路由器只负责把包转发到离目标更近的下一跳，而不知道完整路径。这就是**逐跳转发**（Hop-by-Hop Forwarding）。

## TTL（Time To Live）

TTL是IP数据包头中的一个8位字段，防止数据包在网络中无限循环。

### 工作机制

1. 发送方设置初始TTL值（常见：64、128、255）
2. 每经过一个路由器，TTL减1
3. TTL减到0时，路由器丢弃该数据包，并向源地址发送ICMP "Time Exceeded"消息

### TTL的实际应用

**traceroute（路由追踪）** 就利用了TTL机制：

```
发送第1个包：TTL=1 → 第一个路由器收到后TTL归零 → 返回超时消息
发送第2个包：TTL=2 → 第二个路由器收到后TTL归零 → 返回超时消息
...
发送第N个包：TTL=N → 到达目标主机 → 返回响应

通过收集每跳返回的超时消息，就能绘制出完整的路由路径。
```

### 路由环路问题

如果网络中存在路由环路（如路由器A的默认路由指向B，B的默认路由指向A），没有TTL的话数据包会永远在两个路由器之间来回转发。TTL确保这种包最终被丢弃，避免浪费网络资源。

## 路由协议简介

路由器如何自动学习路由？通过路由协议：

| 协议 | 类型 | 适用范围 | 特点 |
|------|------|----------|------|
| RIP | 距离矢量 | 小型网络 | 简单，最大15跳 |
| OSPF | 链路状态 | 中大型内部网络 | 收敛快，支持区域划分 |
| BGP | 路径矢量 | 互联网骨干 | 连接不同自治系统（AS） |

**OSPF（开放最短路径优先）** 是内部网关协议的首选。每台路由器向邻居通告自己的链路状态，最终每台路由器都有一张完整的网络拓扑图，用Dijkstra算法算出最短路径。

**BGP（边界网关协议）** 是互联网的"胶水"。电信、联通、某通信公司等各大运营商之间通过BGP交换路由信息，让全世界的网络互联互通。
